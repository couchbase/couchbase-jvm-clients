# Contributing

Welcome, and thanks for lending a hand!

We encourage you to start by reading the [Couchbase Community Guidelines](https://www.couchbase.com/community-guidelines).

## Reporting Issues

Please use GitHub Issues to report bugs or request new features.

## Pull Requests

The first time you submit a pull request, a bot will comment with instructions for signing a Contributor License Agreement (CLA).
The bot will also ask you to sign the CLA again if the text of the agreement has changed since your last contribution.
